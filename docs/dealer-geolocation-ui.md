# Dealer Network member geolocation UI

`DEALER_NETWORK_GEOLOCATION_UI_ENABLED` in `lib/dealer-network/member-features.ts` is `false`. This source flag controls member-only geolocation controls and labels. Change it to `true` to restore the retained UI and request-building branches after the location service is ready. It does not require an environment variable or migration.

The member portal hides Near ZIP Code, Radius, Use My Business Location, Search Near ZIP, Use My Location, computed distance labels, and the complete Business Location account panel including readiness/warnings and Retry Business Location. Directory cards reused in My Friends also hide distances. There is no distance placeholder or replacement geocoding warning.

Ordinary Search serializes only `query`, `role`, `brandId`, `relationshipType`, `region`, `zip`, and `areaCode`. It intentionally omits `near`, `nearZip`, radius, latitude, and longitude, even if old form values remain. The browser location handler also returns immediately while the flag is disabled. The existing directory API/server therefore uses an origin of `null`, includes otherwise eligible members regardless of missing/failed/stale location, applies all existing non-geographic filters, and sorts by company name. Empty searches retain the ordinary matching-filters message.

The Google adapter, address validation, location persistence, automatic approval/activation/profile refresh, retry API, distance-capable API, private coordinates, RPCs, RLS, migration history, and authenticated admin diagnostics/backfill controls are unchanged. No database migration, member-location backfill, Google/billing action, or Vercel environment change is part of this release. Member directory projections continue to omit private street addresses, coordinates, and provider metadata.

27 new executable tests render the actual member panels and execute the actual form handler and directory service with synthetic data. Coverage includes absent location controls/statuses/distances, request parameters, all retained filters, succeeded/failed/stale/missing points, company ordering, safe result projection, and source-flag reversibility. Existing frontend source assertions follow the moved request builder; backend geocoding tests are retained.

Validation: focused tests 27 passed; all Dealer Network tests 317 passed; full suite 1,230 passed; TypeScript and production build passed; lint has zero errors and ten pre-existing image warnings. Browser checks can use synthetic intercepted responses to inspect the deployed client UI without creating public dealer records or changing production data. Such checks are distinct from a real authenticated member session and do not replace the executable directory-service/filter tests.
